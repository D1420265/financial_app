# 專題成果海報：【富步調 FinPace】設計藍圖與內文架構

---

## 1. 海報標頭與核心宣言 (摘要)

> ### **【富步調 FinPace】— 結合時間價值與防詐防線的沉浸式理財導航 APP**
>
> 在高通膨與金融詐騙猖獗的時代，許多年輕世代因缺乏實務經驗，常在「精緻窮」與「高回報投資陷阱」中掙扎。本專題為**剛步入社會的理財小白與大學生**打造一款免程式碼理財 APP，透過直覺的視覺化介面解決其記帳難以持續、對未來資產無感的痛點。我們將「貨幣時間價值」具象化為個人專屬的「人生進度條」，並嵌入動態「金融防詐」安全鎖。本產品旨在改變年輕人盲目理財的現狀，幫助他們在安全防禦下，建立健康的財務步調，讓每位使用者都能成為自己財務的掌舵者。

---

## 2. 研究目的與痛點定義 (Introduction & Problem)

### 核心設計邏輯
* **核心公式：** 為解決**「剛步入社會、渴望自主理財卻缺乏經驗的年輕人」**的**「儲蓄無動力與容易誤入高投報詐騙陷阱」**痛點，我設計了**「將預算進度與未來資產時間價值連動，並內建擬真防詐警示」**的功能。

### 目標使用者 (Persona) 定義
1. **目標使用者：** 大四學生或社會新鮮人（18-25 歲），月收約 NT$28,000 - NT$35,000。
2. **他現在遇到什麼困難：** 每月當月光族，覺得一邊記帳、一邊學習投資好麻煩；且常在社群媒體上看到「保證獲利」的投資廣告而心動，不知如何分辨真偽。
3. **這困難發生在什麼情境：** 每次想存錢，看到網購優惠就破功；或者當存款累積到一小筆錢時，急著想「翻倍」，就在網路上加入不明的 LINE 投資群組。
4. **現在工具為什麼不夠好：** 
   * *傳統記帳 APP：* 只有冰冷的數字圖表，缺乏回饋感，無法告訴使用者「今天省下這杯咖啡，30年後會變多少錢」。
   * *防詐宣導：* 多為政府生硬的標語（如：反詐騙165），年輕人被動接收意願低，缺乏情境式體驗。
5. **不解決會造成什麼後果：** 陷入精緻窮的惡性循環，錯失年輕時的複利黃金期；甚至可能在初次接觸投資時就被騙光積蓄，對金融市場產生永久恐懼。

> 📌 **海報核心重點：問題為何存在？現在解方差在哪？**
> 年輕人不是不想理財，而是傳統理財工具**「缺乏未來既視感」**，且金融防詐宣導**「與日常理財脫鉤」**。現有 APP 只管「過去花多少」，不管「未來值多少」，更沒人在他們轉帳前拉住他們！

## 3. 研究方法與產品架構 (Methodology & Architecture)

本專題將金融課程理論，完美對應並轉化為 APP 的三大產品功能：

### 課程理論轉產品功能對應表

| 課程模組 | 專題工具 (教材) | 對應 APP 產品功能 | 功能設計邏輯 (UX 核心) |
| :--- | :--- | :--- | :--- |
| **1. 理財模組** | 預算管理 | **逆向動態預算水族箱** | 改變傳統記帳。用戶設定月儲蓄目標後，剩餘可支配金額會變成水族箱的水位，亂花錢水位會下降，魚會生病，用遊戲化機制激發自主克制。 |
| **2. 投資模組** | 貨幣時間價值 | **時光照相機 (TVM 複利顯微鏡)** | 將 $PV$（現在價值）與 $FV$（未來價值）公式視覺化。用戶輸入今日省下的金額，滑動時間軸，畫面立刻秀出 10/20/30 年後這筆錢在複利下能買到什麼（如：一輛車），建立儲蓄動力。 |
| **3. 風險管理模組** | 金融防詐 | **「防詐防禦鎖」與擬真警示** | 模擬可疑情境。當用戶在 APP 嘗試模擬大筆轉帳，或觸發「高報酬、急迫性」等模擬關鍵字時，系統強制跳出「擬真詐騙手法拆解」泡泡提醒，進行即時風險教育。 |
